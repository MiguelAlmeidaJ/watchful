# Prontidão operacional e homologação

A evidência para conclusão deve estar registrada na [validação](VALIDATION.md). Marcar um item exige verificação no ambiente apropriado.

- [ ] Além Paraíba configurado como território monitorado.
- [ ] Fontes reais disponíveis integradas e verificadas.
- [ ] Coletas automáticas verificadas no ambiente apropriado.
- [ ] Qualidade das medições avaliada consistentemente.
- [ ] Informações indisponíveis identificadas.
- [ ] Mapa territorial funcional.
- [ ] Monitoramento meteorológico funcional.
- [ ] Monitoramento hidrológico funcional.
- [ ] Motor de risco rastreável e testado.
- [ ] Regras sem homologação isoladas.
- [ ] Fluxo de alertas verificado.
- [ ] Notificações implementadas e testadas.
- [ ] Painel web estável.
- [ ] Mobile validado nas plataformas disponíveis e limitações das demais registradas.
- [ ] Isolamento entre organizações comprovado por testes.
- [ ] Mecanismos de segurança implementados e validados.
- [ ] Observabilidade operacional verificada.
- [ ] Pipeline CI/CD implementado.
- [ ] Backup e restauração documentados e ensaiados.
- [ ] Testes críticos aprovados.
- [ ] Builds verificados.
- [ ] Documentação atualizada.
- [ ] Infraestrutura preparada para implantação.
- [ ] Dependências externas e revisões institucionais documentadas.
