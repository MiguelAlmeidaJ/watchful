# ANA, CEMADEN e SGB — piloto
Migração 007. Primeiro estágio: importação administrativa manual, sem simular integração online. ANA exige autorização: https://www.snirh.gov.br/hidroweb/acesso-api e https://www.gov.br/ana/pt-br/assuntos/monitoramento-e-eventos-criticos/monitoramento-hidrologico/orientacoes-manuais/manuais/manual-hidrowebservice_publica.pdf/view . CEMADEN: https://mapainterativo.cemaden.gov.br/ e https://sws.cemaden.gov.br/ (contrato e autorização a validar). Não contornar CAPTCHA. Arquivos originais precisam ser normalizados manualmente; nenhum conversor nativo foi implementado. A origem é declarada pelo administrador, não autenticada.
Formato JSON ANA: lista de objetos com observedAt (ISO 8601 com offset), metric (river_level_m ou discharge_m3_s), value (m ou m³/s). Converter centímetros para metros antes de importar; preservar referência do datum da régua. CEMADEN: metric rainfall_mm, value em mm do intervalo, intervalMinutes obrigatório conforme arquivo original; não importar acumulados cumulativos como incrementos. Máximo 5000 linhas por lote. Sem deduplicação entre lotes; resumo escolhe medição mais recente por estação/variável. Não há avaliação de representatividade nem geração de alertas a partir dessas tabelas.
SGB Além Paraíba: https://rigeo.sgb.gov.br/items/780aa1d9-4846-4473-b1fd-da70097a77bd (setorização histórica); https://rigeo.sgb.gov.br/items/6f4456e9-ef3c-463a-bebc-fd3e0d7d27d4 (suscetibilidade, não setores de risco); https://rigeo.sgb.gov.br/items/dab0f71d-4c50-412e-a3f8-3c43151edd3d (carta geotécnica). Usar QGIS gratuito para converter setores para GeoJSON EPSG:4326, revisar atributos externalId,name,hazard,classification,sourceVersion conforme schema geo. Lotes de até 50; geometrias devem estar dentro da malha municipal. Não alterar geometria ou classificação sem revisão técnica; divergências com malha simplificada devem ser resolvidas antes da importação. Importação utiliza serviço existente, com versões e auditoria. Não foi baixado ou convertido nenhum arquivo SGB nesta etapa.
Sem dependências pagas ou novas bibliotecas. API automatizada ANA/CEMADEN, descoberta de estações, gráficos históricos, rios e dashboard geral ficam pendentes. Build e teste local não realizados. Alertas automáticos permanecem desativados.
