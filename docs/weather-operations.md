# Operação de fontes 2.0
Migração 006 obrigatória antes de iniciar API/worker. Catálogo INMET: API primária, cache PostgreSQL, retry de cinco minutos após falha; alternativa CSV baixado pelo administrador na página oficial https://portal.inmet.gov.br/paginas/catalogoaut (URL de arquivo direto não confirmada). CSV enviado é declarado oficial pelo administrador, não autenticado criptograficamente. Parser aceita delimitadores vírgula/ponto e vírgula, coordenadas decimais e cabeçalhos conhecidos; validar com arquivo real. Catálogo antigo identificado na descoberta; não fornece medições. Sincronização manual via tabela persistente, worker consulta a cada 15s, enfileira job com ID estável, intervalo mínimo de cinco minutos por alvo; enfileiramento não garante coleta. Pode haver sobreposição com agendamentos, lock de ingestão evita concorrência mas job sobreposto pode não coletar. Habilitação de alvos, diagnóstico atualizado a cada 15s na página. Não interrompe coleta em andamento. Sem dependências novas; alertas permanecem desativados.
