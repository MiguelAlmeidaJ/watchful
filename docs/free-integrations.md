# Piloto — fontes gratuitas
Além Paraíba/MG (3101508) é o primeiro território; nenhum código específico de município foi embutido no fluxo. Ação administrativa POST geo/municipalities/:id/boundary/ibge consulta a API pública v3 do IBGE, formato GeoJSON, qualidade intermediária, valida codarea, tamanho, geometria e registra hash de conteúdo (não ano oficial) e auditoria. Geometria simplificada não substitui limite cadastral de precisão nem mapeamento de risco. A resposta real do endpoint não pôde ser verificada neste ambiente; validar localmente. OpenFreeMap Positron (https://tiles.openfreemap.org/styles/positron) é o padrão web, sem chave; atribuição MapLibre preservada. Serviços externos não garantem SLA. Referências: https://openfreemap.org/quick_start/ ; https://www.ibge.gov.br/geociencias/organizacao-do-territorio/malhas-territoriais/15774-malhas.html ; https://open-meteo.com/en/terms . Open-Meteo apenas uso não comercial dentro dos limites vigentes. INMET, CEMADEN, ANA, SGB ainda exigem validação de acesso, termos e cobertura. Central de fontes indica estado cadastral, não disponibilidade ao vivo. Worker e alertas permanecem desligados. Sem migração ou nova dependência. Validar build e importação antes de avançar.
